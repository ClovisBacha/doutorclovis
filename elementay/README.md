# ELEMENTAY

Site conceitual da marca de roupas **Elementay** — moda guiada pelos quatro
elementos da natureza (Fogo, Água, Terra e Ar) e movida pelo bem: grande parte
do lucro é doada a instituições de caridade.

> **Importante:** este projeto é **totalmente independente** do site do
> Dr. Clóvis Bacha. Ele vive nesta pasta apenas por conveniência do repositório
> e não compartilha código, rotas nem banco de dados com o restante do projeto.

## Linhas da marca

| Elemento | Proposta |
| -------- | -------- |
| 🔥 Fogo  | Linha exclusiva e ousada, edições limitadas |
| 💧 Água  | Moda praia e banho de mar, leveza |
| ⛰️ Terra | Performance outdoor e treinos pesados |
| 🌬️ Ar    | Máximo conforto e leveza no dia a dia |

## Como visualizar

É um site estático de arquivo único, sem dependências:

```bash
# abra direto no navegador
open elementay/index.html

# ou sirva localmente
npx serve elementay
```

Todos os preços, percentuais de doação e produtos são **ilustrativos** nesta
primeira versão conceitual.
